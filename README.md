# THN Converter for Python

Cross-platform video converter built with CustomTkinter and FFmpeg.

## Prerequisites

- Python 3.8+
- pip3

## Quick Start

```bash
./install.sh
python3 thn_converter.py
```

## Usage

1. Drag a video file or click "Select File"
2. Choose save location
3. Configure conversion settings
4. Click "Convert"

## Features

- Video codecs: H.264, H.265, ProRes, DNxHD, VP9
- Audio codecs: AAC, MP3, Opus, FLAC, PCM
- Resolution, framerate, and CRF control
- Timecode overlay
- Real-time progress tracking
- Dark/light mode
