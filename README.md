# THN Converter for macOS

Native macOS video converter with SwiftUI interface and FFmpeg backend.

## Prerequisites

- macOS 13.0+
- Xcode Command Line Tools

## Build

```bash
./build.sh
```

## Usage

1. Drag a video file to the designated area
2. Select conversion settings
3. Click "Convert"

## Features

- Video codecs: H.264, H.265, ProRes, DNxHD, VP9
- Audio codecs: AAC, MP3, Opus, FLAC, PCM
- Resolution, framerate, and CRF control
- Timecode overlay
- Real-time progress tracking
